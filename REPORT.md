# Отчёт о реализации

Дата: 20 октября 2026 года.

## Результат

Создано приложение «Нырок» на HTML, CSS и JavaScript с ES-модулями. Зависимостей npm нет. Node.js используется для локального сервера, тестов и сборки. Все исходники и результаты находятся в папке проекта.

Реализованы обзор, дневник с CRUD и фильтрами, календарь, анализ регулярности, статистика, графики, рекорды, JSON-экспорт и импорт. Сохранение — в браузере; сервер не получает данные тренировок. Демонстрационный режим изолирован от постоянного дневника.

## Автоматические проверки

`node --test`: **25 тестов пройдено, 0 ошибок, 0 пропущено** на Node.js 22.14.0.

Проверены:

- Существующие даты, високосные годы, переходы месяцев и лет.
- Необязательные поля обычной тренировки и обязательные поля заплыва на время.
- Отклонение неверных дистанций, времени, стилей, дат, идентификаторов и заметок.
- Формула темпа, округление секунд и переход `1:59,6 → 2:00`.
- Недостаточная история, сортировка дат, исключение повторных посещений в один день.
- Средний интервал, порог напоминания и календарные дни при переходе на летнее время.
- Суммы известной дистанции, текущий месяц, начало недели в понедельник.
- Разделение рекордов по дистанции и стилю, равные результаты, предыдущий заплыв.
- Заполнение пустых периодов графиков и фильтрация истории темпа.
- Экспорт и обратный импорт JSON, неверные файлы, версия, дубликаты, лимит записей.
- Чтение сохранённых данных, ошибки записи и сохранность повреждённых исходных данных.

`node scripts/build.mjs`: **успешно**, 6 статических файлов в `dist/`, синтаксис JavaScript проверен. Локальный сервер запущен с `--dist`; HTTP-проверка главной страницы вернула **200**.

Песочница Windows первоначально препятствовала запуску Node.js (`EPERM` при разрешении пути). Тесты и сборка успешно выполнены после предоставленного разрешения. Позднее повторные запуски не были разрешены; дополнительные изменения были отменены, чтобы итоговые исходники соответствовали уже проверенной сборке.

После этого внесено только небольшое исправление CSS: контейнер прокручиваемой таблицы стал позиционированным, чтобы скрытая подпись не расширяла страницу на узком экране. Исправление синхронно внесено в исходник и `dist`, затем проверено в браузере. JavaScript и тесты остались в ранее проверенной версии. SHA-256 всех шести файлов исходного приложения и `dist` совпадает.

## Проверки интерфейса

В браузере на собранной версии выполнены:

- Первый запуск с пустым дневником.
- Создание обычной тренировки без дистанции и времени.
- Перезагрузка страницы и сохранение ранее добавленной записи.
- Проверка ошибки при попытке сохранить неполный заплыв на время.
- Заплыв 400 м за 8:20: темп **2:05 / 100 м**.
- Изменение результата на 7:20: статистика показывает **1:50 / 100 м**.
- Две записи за один день: **2 тренировки, 1 день посещения**, интервал не рассчитывается.
- Открытие календарного дня и карточки результата.
- Отклонение некорректного JSON без изменения текущих записей.
- Импорт корректного файла через предварительный просмотр и подтверждение замены.
- Сравнение двух заплывов 100 м кролем: **2:00 против 2:05, улучшение на 5 секунд**.
- Строка с `<script>` в заметке отображается как текст.
- Удаление записи через подтверждение, пересчёт рекорда и возврат к пустому дневнику.
- Поиск по заметкам в дневнике на узком экране.
- Мобильный обзор и форма при ширине 390 px; статистика и дневник при 320 px; обзор при 1440 px.
- После исправления CSS горизонтального переполнения страницы нет: при 320 px `scrollWidth = clientWidth = 305`, при 1440 px — `1425`. Разница с шириной окна — полоса вертикальной прокрутки. Широкая таблица и график прокручиваются внутри собственных контейнеров.
- На завершающем этапе журнал ошибок браузера пуст.

Тестовые записи удалены. Данные реального пользователя не использовались.

Снимки демонстрационного режима: `docs/screenshots/desktop.png` и `docs/screenshots/mobile.png`.

## Границы проверки и ограничения

- Формирование и обратное чтение экспортируемого JSON проверены автоматическим тестом; сохранение файла кнопкой в папку загрузок браузера отдельно не проверялось.
- Не проводились проверки на физических телефонах, Safari, Firefox и отдельные испытания со скринридером.
- Не проводилось нагрузочное тестирование на предельном количестве записей.
- Проверки переполнения и повреждения хранилища выполнялись через тестовые реализации хранилища, без изменения настроек браузера.
- Нет облачной синхронизации, push-уведомлений, автоматических резервных копий, PWA и доступа по локальной сети.
- Импорт заменяет текущую историю. Очистка данных браузера удаляет локальный дневник; для восстановления нужна JSON-копия.
- Хранилище привязано к браузеру, профилю и адресу. Для открытия нужен запущенный локальный сервер.
- Дневник рассчитан на персональное использование. Полная транзакционная защита одновременной записи из нескольких вкладок не реализована.

Инструкция запуска и правила расчётов приведены в `README.md`.
