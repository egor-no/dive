# Нырок — личный дневник плавания

Локальное адаптивное веб-приложение на русском языке. Без аккаунтов, облака, внешних шрифтов, аналитики и сторонних JavaScript-библиотек.

## Запуск на Windows

Нужен установленный **Node.js 20 или новее**. Проект проверен с Node.js 22.14.0. Устанавливать зависимости через `npm install` не нужно.

1. Откройте PowerShell в папке проекта.
2. Выполните:

```powershell
node scripts/server.mjs
```

3. Откройте в браузере **http://localhost:4173**.
4. Оставьте терминал открытым. Чтобы остановить приложение, нажмите `Ctrl+C`.

Альтернатива — двойной щелчок по `start.bat`, затем открытие того же адреса в браузере.

При следующем запуске используйте **тот же браузер, профиль и адрес**. Записи появятся автоматически. Двойной щелчок по `index.html` не поддерживается: JavaScript-модулям нужен локальный HTTP-сервер.

Если порт занят, возможно, приложение уже работает — сначала откройте адрес. Чтобы выбрать другой порт:

```powershell
$env:PORT = "4174"
node scripts/server.mjs
```

Другой порт создаёт отдельное хранилище браузера. Для переноса записей используйте экспорт и импорт. Сервер слушает только `127.0.0.1`; доступ с других устройств по локальной сети не включён.

## Проверка и сборка

```powershell
node --test
node scripts/build.mjs
node scripts/server.mjs --dist
```

Сборка проверяет синтаксис JavaScript и создаёт статическую версию в `dist/`. Последняя команда обслуживает именно эту версию. Предварительно остановите обычный сервер, если он занимает тот же порт.

Также доступны команды `npm.cmd start`, `npm.cmd test`, `npm.cmd run build`, `npm.cmd run preview`. В PowerShell вариант `npm.cmd` работает без изменения политики выполнения PowerShell-скриптов.

## Возможности

- Обзор, дневник, календарь и статистика сохраняют прежний внешний вид и навигацию.
- Новая тренировка создаётся со статусом **«Запланирована»**. Можно выбрать будущую дату. Кнопка **«Сохранить план»** сохраняет программу и черновые результаты. **«Отметить выполненной»** сохраняет текущие изменения и учитывает посещение бассейна. Для выполненной тренировки доступны **«Сохранить изменения»** и **«Вернуть в планы»**; результаты при этом не теряются. Сам ввод времени статус не меняет.
- **Программа:** именованные блоки, количество кругов всей последовательности, упражнения с собственной дистанцией, стилем, техникой, описанием, плановым временем и отдыхом.
- Блоки и упражнения можно переставлять, удалять и сворачивать. Названия «Блок 1», «Блок 2» создаются автоматически. Дополнительные поля скрыты под раскрываемыми настройками. Отдых между кругами виден только при нескольких кругах; переход к одному кругу сохраняет прежнее значение. Кнопки добавления находятся снизу; предыдущее заполненное упражнение сворачивается.
- **Результаты внутри упражнения:** раскройте карточку и строку «Времена». Число позиций равно числу кругов; номер задаётся местом в сетке. Неизвестные времена оставьте пустыми. Для длинных серий доступны страницы по 16 позиций, на узком экране — два поля в строке. Режим «Только лучший» показывает одно поле без номера круга. Смена режима с заполненными данными требует подтверждения очистки.
- При уменьшении числа кругов с заполненными временами приложение спрашивает подтверждение удаления лишних результатов. Увеличение добавляет пустые позиции. Единственный лучший результат не удаляется при изменении кругов.
- **Быстрый ввод из дневника:** раскройте программу тренировки и нажмите на упражнение или значок часов. Небольшое окно редактирует только его результаты, сохраняя дату, статус и структуру тренировки. Сохранение обновляет показатели; отмена не меняет запись. В заголовках показаны лучшее время текущего упражнения и число заполненных результатов.
- Время: `49.82`, `49,82`, `1:48.37`, `12:35.06`. Значение `1:48` равно `1:48.00`. Общая фактическая продолжительность вводится отдельно.
- **Копирование:** «Добавить тренировку → На основе предыдущей». Поиск по названию, свежие записи сверху. Копируется программа с новыми идентификаторами и сегодняшней датой; статус становится «Запланирована». Результаты, фактическое время и комментарий очищаются.
- Щелчок вне формы не закрывает её. Закрытие изменённой формы требует подтверждения; отмена не сохраняет изменения. При перезагрузке изменённой формы используется стандартное предупреждение браузера.
- Запланированные записи отмечены в дневнике и пунктиром в календаре. Есть фильтры по статусу и месяцу.
- Импорт/экспорт JSON, демонстрационный дневник без записи в постоянное хранилище.

## Правила расчётов

- Дистанция блока = сумма дистанций упражнений × количество кругов. Круг повторяет всю последовательность. Общая дистанция — сумма блоков, независимо от числа заполненных результатов.
- Без блоков можно сохранить ручную дистанцию либо оставить её неизвестной. Неизвестная дистанция не добавляет метры.
- В статистику, графики, регулярность и рекорды входят только выполненные тренировки. Черновые результаты планов начинают учитываться после смены статуса.
- Общее фактическое время не рассчитывается из результатов. Плановое время и отдых никогда не используются как измеренное время.
- После промежуточного упражнения действует его отдых. После последнего упражнения круга он заменяется отдыхом между кругами; после последнего круга — отдыхом после блока. Эти паузы не складываются. Примерная длительность программы пока не рассчитывается.
- Результаты хранятся целыми сотыми секунды. Рекорды сравниваются без округления; темп на 100 м отображается с округлением до сотой.
- Ключ рекорда: **дистанция + стиль + уточнение техники**. Пустая техника означает обычный стиль. Непустые уточнения образуют отдельные категории: регистр не учитывается, лишние пробелы убираются, `ё` приравнивается к `е`. Синонимы автоматически не объединяются.
- «Только лучший» — один результат без номера круга, который не дублируется среди кругов. Равные времена сохраняют первый результат. Порядок сравнений: дата и время создания тренировки, блок, круг, упражнение.
- Регулярность: средний интервал между уникальными датами выполненных тренировок за всю историю. Нужны минимум два разных дня. Несколько тренировок за день дают один день посещения.
- Напоминание появляется при паузе строго больше `max(1,5 × средний интервал, средний интервал + 1 день)`.
- Неделя начинается в понедельник, месяц календарный. «Сегодня» берётся по локальному времени устройства; разница календарных дней рассчитывается через UTC.

## Хранение и совместимость

`localStorage`, ключ `nyrok.workouts.v1` остаётся прежним. Экспорт имеет **version: 3**. Импорт принимает версии **1, 2 и 3**, полностью проверяет файл и показывает сводку до замены дневника. Частичный импорт не выполняется. Импорт заменяет, а не объединяет записи.

Старые записи преобразуются в памяти при чтении; исходное хранилище не очищается и не перезаписывается до явного сохранения пользователем. Каждое задание версии 2 становится отдельным блоком с одним упражнением и одним кругом. Старые тренировки получают статус «Выполнена».

Дата, название, комментарий, дистанции, стиль и результаты сохраняются. Старые продолжительности заданий остаются в справочных полях `legacy`, видны в форме и карточке и не превращаются в план или результат заплыва. Если прежняя версия вычисляла общее время по всем заданиям, это уже известное время переносится в общее фактическое время; прежнее ручное значение также сохраняется в `legacy.manualDurationCs`.

Обычная запись версии 1 остаётся без блоков с ручными итогами. Старый заплыв на время становится одним упражнением с измеренным результатом; его время не объявляется общей продолжительностью.

Структура версии 3:

```text
workout: id, date, title, status, blocks[], distance, durationCs,
         style, comment, createdAt, legacy?
block:   id, title, rounds, exercises[], restBetweenCs, restAfterCs
exercise:id, distance, style, technique, description, plannedTimeCs,
         restAfterCs, resultMode, results[], legacy?
result:  id, round, timeCs
```

Порядок массивов определяет порядок блоков и упражнений. `resultMode` — `rounds` или `best`; в последнем случае единственный результат имеет `round: null`. Пустые времена не создают результат. Все поля `*Cs` — целые сотые секунды либо `null` для неизвестного значения. `distance` тренировки применяется только без блоков; `style` тренировки сохраняет сведения ранних записей.

Для копии: **Данные и настройки → Скачать**. Для восстановления: **Импорт → JSON → проверить сводку → Заменить дневник**. При повреждённых данных доступна кнопка «Скачать исходник»; ошибочное сохранение не заменяет старые данные.

Ограничения: импорт до 5 МБ, до 10 000 тренировок, названия и уточнение техники до 200 символов, описание упражнения до 500, общий комментарий до 2 000; дистанция упражнения или ручная дистанция 1–100 000 м; отдельное время от 0,01 секунды до 7 дней. Количество кругов — положительное безопасное целое число; итоговая дистанция также должна точно представляться целым числом JavaScript. Выполненные тренировки не могут иметь будущую дату.

Браузер привязывает данные к адресу, порту и профилю. `localhost` и `127.0.0.1` имеют разные хранилища. Данные не отправляются серверу. Очистка данных браузера удаляет дневник; резервные копии сохраняются вручную. Автосохранения несохранённой формы и синхронизации с облаком нет.

```text

src/editor.js              Компактный конструктор программы
src/results-editor.js      Сетка результатов и защита несохранённых изменений

src/storage.js             Чтение и запись localStorage
src/styles.css             Адаптивные стили
scripts/server.mjs         Локальный HTTP-сервер
scripts/build.mjs          Проверка синтаксиса и статическая сборка
tests/domain.test.js       Расчёты, статусы, копирование и миграции
tests/storage.test.js      Сохранение, повторное чтение и обработка ошибок
tests/results-editor.test.js Сетка, изменение кругов и быстрое редактирование
```
