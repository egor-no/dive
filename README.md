# Нырок — личный дневник плавания

Локальное адаптивное веб-приложение на русском языке. Без аккаунтов, облака, внешних шрифтов, аналитики и сторонних JavaScript-библиотек.

## Запуск на Windows

Нужен установленный **Node.js 20 или новее**. Проект проверен с Node.js 22.14.0. Устанавливать зависимости через `npm install` не нужно.

1. Откройте PowerShell в папке проекта.
2. Выполните:

```powershell
node scripts/server.mjs
```

3. Откройте в браузере **http://localhost:4173**.
4. Оставьте терминал открытым. Чтобы остановить приложение, нажмите `Ctrl+C`.

Альтернатива — двойной щелчок по `start.bat`, затем открытие того же адреса в браузере.

При следующем запуске используйте **тот же браузер, профиль и адрес**. Записи появятся автоматически. Двойной щелчок по `index.html` не поддерживается: JavaScript-модулям нужен локальный HTTP-сервер.

Если порт занят, возможно, приложение уже работает — сначала откройте адрес. Чтобы выбрать другой порт:

```powershell
$env:PORT = "4174"
node scripts/server.mjs
```

Другой порт создаёт отдельное хранилище браузера. Для переноса записей используйте экспорт и импорт. Сервер слушает только `127.0.0.1`; доступ с других устройств по локальной сети не включён.

## Проверка и сборка

```powershell
node --test
node scripts/build.mjs
node scripts/server.mjs --dist
```

Сборка проверяет синтаксис JavaScript и создаёт статическую версию в `dist/`. Последняя команда обслуживает именно эту версию. Предварительно остановите обычный сервер, если он занимает тот же порт.

Также доступны команды `npm.cmd start`, `npm.cmd test`, `npm.cmd run build`, `npm.cmd run preview`. В PowerShell вариант `npm.cmd` работает без изменения политики выполнения PowerShell-скриптов.

## Возможности

- **Обзор:** приветствие и дата, последняя тренировка, количество тренировок и известная дистанция за текущий месяц, средний интервал, календарь и дружелюбное сообщение о регулярности.
- **Дневник:** создание, просмотр, редактирование и удаление; поиск по заметкам, стилю и дистанции; фильтры по месяцу и типу.
- **Обычная тренировка:** достаточно даты. Дистанция, время, стиль и заметка необязательны.
- **Заплыв на время:** обязательны дата, дистанция, результат и стиль; темп на 100 м рассчитывается автоматически.
- **Календарь:** переход между месяцами, открытие дня и несколько записей в один день.
- **Статистика:** общие показатели, текущая неделя и месяц, количество тренировок за 8 недель или 6 месяцев, метры за 6 месяцев, график темпа, таблица личных рекордов.
- **Пример:** можно временно открыть заполненный дневник. Он не записывается в постоянное хранилище и не заменяет ваши записи.
- **Данные:** JSON-экспорт, проверка файла и предварительный просмотр перед импортом.

На смартфоне боковое меню заменяется нижней навигацией. Кнопка «+» в заголовке открывает форму тренировки.

## Правила расчётов

- Все тренировки учитываются в количестве, включая записи без дистанции.
- Неизвестная дистанция не прибавляет метры к сумме.
- Средний интервал = сумма промежутков между соседними **уникальными датами** / число этих промежутков. Рассчитывается по всей истории, а не только текущему месяцу.
- Пока нет двух разных дней посещения, интервал не показывается.
- Разница календарных дней вычисляется через UTC, без влияния переходов на летнее время. «Сегодня» определяется по локальной дате устройства.
- Напоминание появляется, когда пауза **строго больше** `max(1,5 × средний интервал, средний интервал + 1 день)`.
- Неделя начинается в понедельник. Месяц — календарный.
- Темп = `время в секундах / дистанция в метрах × 100`; отображается с округлением до секунды.
- Личный рекорд — минимальное полное время для отдельной пары **дистанция + стиль**. При равных временах сохраняется первая запись.
- В карточке заплыва сравнение идёт с предыдущим подходящим результатом, а не с личным рекордом. Внутри одной даты порядок определяется временем создания записи.

## Хранение и резервные копии

Хранилище — `localStorage`, ключ `nyrok.workouts.v1`. Данные не отправляются серверу. Сервер только выдаёт HTML, CSS, JavaScript и значок.

Браузер привязывает данные к адресу, порту и профилю. `localhost` и `127.0.0.1` — разные хранилища. Приватный режим, очистка данных сайта или удаление профиля могут стереть дневник.

Для резервного копирования: **Данные и настройки → Скачать**. Для восстановления: **Импорт → выбрать JSON → проверить сводку → Заменить дневник**. Импорт **заменяет**, а не объединяет записи. Отмена не меняет дневник.

Формат:

```json
{
  "version": 1,
  "exportedAt": "2026-10-20T08:00:00.000Z",
  "workouts": [
    {
      "id": "example-1",
      "type": "timed",
      "date": "2026-10-19",
      "distance": 100,
      "duration": 125,
      "style": "freestyle",
      "comment": "Спокойный заплыв",
      "createdAt": "2026-10-19T08:00:00.000Z"
    }
  ]
}
```

`duration` — целые секунды, `distance` — целые метры. У обычной тренировки эти поля могут быть `null`, `style` — пустой строкой. Поддерживаемые стили: `freestyle`, `breaststroke`, `backstroke`, `butterfly`, `medley`, `mixed`.

Файл полностью проверяется до сохранения. Неподдерживаемая версия, неверные поля и повторяющиеся идентификаторы отклоняются. Ограничения: 5 МБ на импорт, 10 000 записей, 2 000 символов на заметку, дистанция 1–100 000 м, время 1–604 800 секунд. Даты в будущем не разрешены.

При ошибке сохранения приложение сообщает, что изменения не сохранены. Повреждённые данные при старте не затираются; их можно скачать через «Скачать исходник», затем восстановить корректную копию.

## Ограничения первой версии

Нет синхронизации между устройствами, внешних уведомлений, аккаунтов, установки как PWA и автоматического резервного копирования. Интернет для работы не требуется, но для открытия приложения должен работать локальный сервер. Изменения в нескольких вкладках обновляются через событие `storage`; полноценные транзакции одновременной записи не реализованы.

Обработка больших дневников синхронная; нагрузочное тестирование на 10 000 записей не проводилось. Доступ со смартфона к серверу на Windows не настроен: адаптивность относится к интерфейсу, а не к сетевой доступности.
